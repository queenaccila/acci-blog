I finally updated my designs for some of the main cast of characters!
I'm considering redesigning my game with a much smaller scope, as some part of me still doesn't want to get rid of this idea just yet.

A lot of the anatomy is really simplified down to more basic shapes, mainly because I'm anticipating animating them a lot in 2D.
Even with 2D rigging tools like Spine 2D and Moho, I know it's gonna be painful to animate if the anatomy takes too long to draw per frame.
Not only this, but I think if I want to make something aimed towards a younger audience, I want to simplify features for the average kid or teen to take in and recognize.

I hope to add more to the cast in the future!
I have some redesigns I want to finish, or add more to the list!
